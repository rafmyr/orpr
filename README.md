# ORPR — Open Retail Process Reference

**Otwarty standard referencyjnej architektury procesowej dla retailu.** ORPR porządkuje domeny,
procesy, przepływy, odpowiedzialności i styki między obszarami organizacji handlowej.

## Wydanie v0.1.0

To publiczny snapshot produktu przygotowany z prywatnego repozytorium warsztatowego. Zawiera:

- mapę nawigacyjną 74 procesów w 22 obszarach oraz jednego kandydata;
- sześć pełnych kart procesów z domen CAT i SAL;
- przepływy przekrojowe, mapowania i profile referencyjne;
- szablony kart, licencje, znane ograniczenia, manifest integralności i informację o pochodzeniu.

Nie zawiera warsztatowych rejestrów decyzji, materiałów recenzyjnych, danych adopterów,
prywatnej struktury regulatory-matrix ani historii prywatnego repozytorium.
